    if (rng.NextInt(2) == 0) await PowerCmd.Apply<VulnerablePower>(choiceContext, enemies, 1m, …);
    else                     await PowerCmd.Apply<WeakPower>(choiceContext, enemies, 1m, …);

### 实测出的字数基准（重要，以后设计卡都按这个）

读 `ManosabaLin/localization/zhs/cards.json` 全部 **573** 条 `.description`（含富文本）：
