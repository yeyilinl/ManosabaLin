## 修复「变身的魔法」TransformationMagic 卡无效果

**本地化规格**（zhs/eng/jpn/rus 一致）：`回合开始时，可以选择1张手牌，本牌变身为该牌的复制`
→ 触发点是**回合开始时（在手牌中）**，不是打出时。

**根因**（`git diff HEAD` 对比得出）：
- 工作区里这张卡被改成了 `OnPlay` 版本，逻辑把**被选中的牌**换成它自己的复制再把自身移除 → 净效果≈0。
- HEAD 里是 `AfterPlayerTurnStart`（方向正确），但有真 bug：`newCard` 用
  `CombatState.CreateCard(...)` 创建、升级后**从未加入手牌**，随后直接把 `source` 移除
  → 卡牌凭空消失 = 玩家看到的"没有效果"。

**修复**：改回回合开始触发，并用基底的 `CardCmd.Transform(source, replacement)`
（语义就是"变身"：在原牌位替换为替换牌 + 变身表现）。要点：
- `CardSelectorPrefs(SelectionScreenPrompt, 0, 1)` —— min 0 = 「可以」选择（可选写法，与 Ananlin 系一致）
- 手牌里除自身外无牌时提前 return，避免弹出无目标的选择界面
- 守卫 `source.IsTransformable` 与 `CombatState != null`（`CardCmd.Transform` 会抛 `InvalidOperationException`）
- 复制只带升级等级（与 HEAD 一致），不带走幻附魔/附魔/诅咒

**编译**：0 个 CS 错误（428 警告）。末尾 2 个 MSB3027/MSB3021 是部署失败——
`SlayTheSpire2.exe` 正在运行锁住了 `mods/ManosabaLin/ManosabaLin.dll`，关游戏后重新 build 即可部署。

### 补做：「复制」要连附魔/幻附魔/诅咒一起带

初版沿用 HEAD 的 `CombatState.CreateCard(CanonicalInstance, owner)` + 手动升级，只带**基础牌 + 升级等级**。
用户要求完整复制 → 改用基底的 **`CardModel.CreateClone()`**（`CardModel.cs:2182`）：

```csharp
var replacement = target.CreateClone();
await CardCmd.Transform(source, replacement);
```

`CreateClone()` = `CardScope.CloneCard(this)` → `MutableClone()`（`MemberwiseClone` + `DeepCloneFields` + `AfterCloned`），
复制内容：升级等级/Owner 等标量、关键词(Local)、DynamicVars、能量/星星费用改动、
**附魔 Enchantment**、**幻附魔 Affliction**、**MinionLib 组件**（`ComponentsCardModel.DeepCloneFields` → `c.DeepClone()` + `Attach`）；
同时重置 `DeckVersion`/事件委托等，设 `ExhaustOnNextPlay = false`、`_cloneOf = 原牌`。
原版 **`DualWield`**（选一张手牌获得其复制）用的就是这条路径，是权威先例。

`IsClone` 语义是**有益**的：基底消费点（`Stomp`/`Midnight` 跳过重算费用、`SwordSagePower` 跳过重复挂重放）
都是"作为克隆进入战斗 = 继承原牌当前状态、不重跑一次性初始化"。

**结论：以后在本模组里做"复制一张牌"，一律用 `source.CreateClone()`，不要用 `CreateCard + 手动升级`。**

**编译**：`STS2_SKIP_PCK_EXPORT=1 dotnet build ManosabaLin.sln` → **0 错误**（424 警告），部署成功。

**遗留待定**：该卡可打出（0 费 Skill）但打出无效果。若要防止误打出可改 -1 费 + `Unplayable`；
若希望打出也能变身，可在 `OnPlay` 复用同一段逻辑。用户未定。
