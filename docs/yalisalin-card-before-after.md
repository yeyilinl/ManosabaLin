### 火色侧的复杂度来源（从对比里数出来）

| 来源                   | 涉及卡数                                                                                                          | 处理           |
| -------------------- | ------------------------------------------------------------------------------------------------------------- | ------------ |
| **封存**（选择格子 + 抽回量表）  | 6 张（Reversecalculation / Temperatureproof / Pocketmatchbox / Ashinpages / Unusedconclusion / BoundPrometheus） | **机制全删**（卡保留，按定稿表换卡面） |
| **升温 / 强升温**         | 5 张（WitchPrisoner / Pocketmatchbox / Samewrongproblem / Deadlinehandoff / Thirteenthlistener）                 | **机制全删**（卡保留） |
| **「本回合上次消耗的颜色」记忆状态** | 2 张（Pocketmatchbox / Samewrongproblem）                                                                        | 全删           |
| **「满格 / 未满格」双向分支**   | 3 张（Deadlinehandoff / Burntthermometerpaper / Samewrongproblem 近亲）                                            | 改成单向「若已满则强化」 |
| **卡上自弹的选择 UI**       | 3 张（Temperatureproof / Pocketmatchbox / Reversecalculation）                                                   | 全删           |

> ⚠️ **升级版也没能救回这些复杂度**：`Temperatureproof` / `Pocketmatchbox` 的升级只是**多加一句格挡/能量**，  
> `Unseenkindling` 的升级只是**多加一句格挡** —— 原设计的升级**没有解复杂度，只是加数值**。

## 三、反思：对比暴露的四个设计问题

### 反思 1 · 我套模板，把独特的设计改成了普通的设计

| 卡              | 原设计解决的问题                         | 我 v6 的设计          | 谁更好       |
| -------------- | -------------------------------- | ----------------- | --------- |
| `KuanShuYinJi` | 宽恕 → **下回合按层数抽牌**（把宽恕转成**过牌爆发**） | 宽恕 → 回血 2 点（普通续航） | **原设计更好** |
| `NiNiZhiZheng` | 自惩 → **每层 1 力量**（把自惩转成**永久成长**）  | 自惩 → 抽 1 张（普通过牌）  | **原设计更好** |

**根因**：我先定了「宽恕→续航、自惩→过牌、自惩→成长」三个模板就往卡上套，  
**没有先问「这张卡原本在解决什么问题」**。

⇒ **修正原则：改卡前先问"它原本解决什么问题"。原设计若已解决独特问题，就保留其独特性、只简化表达。**

### 反思 2 · 有一张卡的功能我完全改掉了，而原功能是这个体系缺的

`XingJiaJiaShen` 原效果：**每回合第 1 张诅咒打出后，减 1 费、添加消耗，然后回到手牌。**  
它解决的是「**诅咒打出去就没了**」——让诅咒**能重复使用**（自惩一次，回手再自惩）。  
这是原罪体系里**唯一**处理「诅咒是一次性消耗品」这一痛点的卡（升级后作用于前 2 张，更强）。  
我把它改成「自惩→力量」，等于**删掉了唯一的「可重复使用」通道**。  
⇒ **修正**：保留原功能，抓位定为「**循环**」。


### 反思 3 · 我丢了"回收"这个抓位

`ZhiMingHuanYa` 原效果是**从弃牌堆把诅咒捞回抽牌堆**——也就是「**回收**」（原版 `Hologram`/`Headbutt` 那一类）。  
我的新设计把它改成「宽恕→格挡」，**丢掉了原罪体系唯一的「从弃牌堆回收诅咒」通道**。  
⇒ **修正**：`ZhiMingHuanYa` 保留「**回收**」抓位。

### 反思 4 · 删完封存/升温后没检查是否留下空缺

删掉封存（6 张）、升温/强升温（5 张）之后：

- 「**够深层**」只剩 `Reversecalculation` + `Dontcooldown` 两张 —— 偏少（浅橙是最值钱的一层）。
- 封存原本承载的「**把火色存起来、延后使用**」**完全消失**，而「囤积」在「填满→引爆」的节奏里是有意义的。

⇒ **修正结论（用户 2026-09-26 裁定）**：  
「够深层」**不新增卡**，改为**强化现有 2 张**（`Reversecalculation` 引爆效果翻倍、`Dontcooldown` 提升层数格挡）；  
「囤积」**不做**。火色**锁定 21 张**。
